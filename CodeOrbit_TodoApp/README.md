# Task 2 — To-Do List Web App

## Features
Add, edit, delete, mark complete and clear completed tasks. Tasks persist after page refresh using browser `localStorage`.

## Run
Open `index.html` in a browser. No server or dependencies required.

## Test
1. Add a task and refresh: it should remain.
2. Edit a task and refresh: the edit should remain.
3. Mark complete and refresh: completion should remain.
4. Delete a task: it should disappear.
5. Clear completed: only unfinished tasks should remain.

Storage is local to the browser and origin; clearing browser data removes saved tasks.
