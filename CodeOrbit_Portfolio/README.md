# Task 1 — Personal Portfolio Website

Responsive HTML/CSS/JavaScript portfolio with About Me, Skills, Projects and Contact sections.

## Run
Open `index.html` in your browser. No installation required.

## Customize before submission
Replace `Your Name`, bio, email, GitHub URLs and project details with your real information. GitHub links currently point to the GitHub homepage as placeholders.

## Files
- `index.html`: structure
- `style.css`: styling and mobile layout
- `script.js`: mobile navigation and copyright year
